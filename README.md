# Archive-Of-Things
Self Hosted Archive that stores things you need, might need, may need and possibly need.
Created for the sole reason of wanting to have everything in one manageable space, without the need of paying for extra, or handing over your data to others.

## AOT or Archive of things - An isolated Safe Space
Can store personalized archives or collections with item tagging, custom labels(e.g. status). When AOT is deployed in an device, user should pre-allocate space for AOT to use, or just use the entire storage space.
